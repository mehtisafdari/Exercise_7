# تمرین هفتم — خوانندگان و نویسندگان با الگوریتم FCFS

الگوریتم اصلی پروژه‌های قبلی شما **FCFS** است. این پروژه مسئله Readers-Writers را با چهار روش بررسی می‌کند:
- Dekker و Peterson: نمایش انحصار متقابل برای دقیقاً دو شرکت‌کننده.
- Semaphore و Monitor: پیاده‌سازی مسئله چندخواننده/چندنویسنده.

**نکته علمی:** FCFS سیاست ترتیب‌دهی درخواست‌هاست؛ Readers-Writers مسئله همگام‌سازی دسترسی به داده مشترک است. Dekker و Peterson در شکل کلاسیک فقط برای دو thread هستند، پس در این پروژه به‌صورت نمونه دوشرکت‌کننده‌ای نمایش داده شده‌اند. Semaphore و Monitor از چند خواننده و نویسنده پشتیبانی می‌کنند. بنابراین مقایسه زمان اجرای این دو گروه، مقایسه سرعت مستقیم و هم‌شرایط نیست.

## اجرا
Python 3.8+ لازم است؛ کتابخانه خارجی نیاز نیست:
```bash
python src/readers_writers_fcfs.py
```
نتیجه در `results/summary.csv` ذخیره می‌شود.
